Україна - Синхронізація банків

Інтеграція з українськими банками для Odoo 19

Про модуль

Базовий модуль для інтеграції з українськими банками. Забезпечує автоматичну синхронізацію банківських виписок та транзакцій безпосередньо в Odoo.

Модулі провайдерів (l10n_ua_bank_privat, l10n_ua_bank_mono) наслідують цей модуль та реалізують специфічні API-виклики для кожного банку.

Основні можливості

  • Розширення банків (код МФО)
  • Валідація українських IBAN
  • Налаштування підключень до банків
  • Завдання синхронізації з керуванням станами
  • Логування імпорту зі збереженням сирих даних
  • Повторна обробка без повторного завантаження
  • Майстер синхронізації з вибором періоду
  • Генерація банківських виписок
  • Експорт виписок у PDF та XLSX

Привіт! Створюю відкриті модулі української локалізації Odoo для повноцінної заміни 1С:

  • 📊 Бухгалтерський та фінансовий облік за українськими стандартами
  • 📋 Податкова звітність та електронний документообіг
  • 👥 HR-модуль (заміна ЗУП) — кадри, зарплата, табелі
  • 🏭 Операційний облік — склад, виробництво, продажі

Навіщо це потрібно: тисячі українських компаній досі сидять на російському софті, бо немає повноцінної альтернативи. Odoo — це потужна європейська ERP з відкритим кодом, але без якісної української локалізації перехід неможливий.

Куди підуть кошти: розробка та тестування модулів, документація українською, підтримка спільноти.

Модулі будуть у відкритому доступі — для всіх, хто хоче позбутися російських технологій.
