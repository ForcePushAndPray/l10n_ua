# Ukraine - Budget Base (Public Sector)

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Фундамент бухгалтерського обліку для українських бюджетних установ
(розпорядники бюджетних коштів, освіта, медицина, ОМС тощо).

## Що дає модуль

* Класифікатори бюджетного обліку:
  * **КЕКВ** — економічна класифікація видатків (~55 кодів з ієрархією)
  * **КФК** — функціональна класифікація (~75 кодів за COFOG-структурою)
  * **КПКВК** — програмна класифікація (стартовий набір МОН/МОЗ на 2025 р.)
  * **КВКВ** — відомча класифікація (ГРБК): МОН, МОЗ, Мінфін, КМУ тощо
* Розширення стандартного `account.account`:
  * Прапорець «Рахунок держсектору»
  * КЕКВ/КФК за замовчуванням
  * Прив'язка до фонду (загальний / спеціальний / будь-який)
* Розширення `account.move` / `account.move.line`:
  * КЕКВ, КФК, КПКВК, КВКВ, фонд на рівні рядка
  * КПКВК і фонд на рівні документа з каскадним розповсюдженням
  * Валідація узгодженості фонду рядка з обмеженням рахунку

## Що НЕ входить (буде в інших модулях)

* `l10n_ua_budget_estimate` — кошториси, плани використання
* `l10n_ua_budget_treasury` — інтеграція з ДКСУ, реєстраційні рахунки
* `l10n_ua_budget_reports` — форми 2д/2м/4-1д тощо, меморіальні ордери
* `l10n_ua_education_base` — освітня специфіка (контингент, групи, заклади)

## Залежності

* `account` (стандартний Odoo)
* `l10n_ua_account_base` (українська локалізація)

## Встановлення

```bash
./venv/bin/odoo -d <db> -i l10n_ua_budget_base --stop-after-init
```

## Нормативна база

* **Бюджетний кодекс України** № 2456-VI від 08.07.2010 — https://zakon.rada.gov.ua/laws/show/2456-17
* **Наказ Мінфіну № 11 від 14.01.2011** — «Про бюджетну класифікацію» (КЕКВ/КФК/КПКВК/КВКВ — щорічно оновлюються)
* **Наказ Мінфіну № 333 від 12.03.2012** — «Інструкція щодо застосування економічної класифікації видатків» — https://zakon.rada.gov.ua/laws/show/z0456-12
* **Наказ Мінфіну № 1203 від 31.12.2013** — «План рахунків бухгалтерського обліку в державному секторі» — https://zakon.rada.gov.ua/laws/show/z0161-14

⚠️ **Усі довідники потребують щорічного оновлення** — закон про Державний бюджет
змінює КПКВК щороку. Перед використанням у проді — звірити з актуальною
редакцією на rada.gov.ua і treasury.gov.ua.

## Обмеження

* Стартовий набір КПКВК — лише МОН (220) і МОЗ (210) на 2025 р. Повний
  довідник (~3000 рядків) рекомендується вантажити з .dbf-файлу
  Держказначейства (`treasury.gov.ua/file-storage/normativno-dovidkova-informatsiya`).
* План рахунків держсектору (Наказ № 1203) не входить у поточну версію —
  буде окремий модуль з chart_template.
* Інтеграції з Казначейством (виписки, платіжки) ще не реалізовані.
