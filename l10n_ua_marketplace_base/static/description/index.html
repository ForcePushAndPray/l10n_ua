🛒 Україна - Маркетплейси (Базовий модуль)

Інтеграція українських маркетплейсів для Odoo 19

📦 Про модуль

Базовий модуль для інтеграції з українськими маркетплейсами. Надає спільну інфраструктуру для:

  • Rozetka — найбільший маркетплейс України
  • Prom.ua — популярний B2B/B2C маркетплейс
  • Epicentr — маркетплейс будівельних матеріалів
  • Allo — маркетплейс електроніки
  • Hotline — агрегатор цін (тільки фід)
  • Price.ua — агрегатор цін (тільки фід)

✨ Основні можливості

  • Конфігурація бекендів — налаштування підключень до різних маркетплейсів
  • Управління прайслистами — створення окремих прайслистів для кожного маркетплейсу
  • Імпорт замовлень — автоматичне завантаження замовлень з маркетплейсів
  • YML/XML фіди — генерація товарних фідів у форматі Yandex Market
  • Webhook підтримка — миттєве отримання повідомлень від маркетплейсів
  • Синхронізація залишків — автоматичне оновлення наявності товарів
  • Синхронізація цін — автоматичне оновлення цін
  • Пошук/створення клієнтів — налаштовуваний пошук за телефоном/email

🏗️ Архітектура

Модуль створює наступні моделі:

Модель Призначення
marketplace.backend Конфігурація підключення до маркетплейсу
marketplace.pricelist Прайслист для публікації на маркетплейсі
marketplace.pricelist.item Товарна позиція в прайслисті
marketplace.order Замовлення з маркетплейсу
marketplace.category Категорії маркетплейсу

⚙️ Налаштування бекенду

Кожен бекенд може мати наступні налаштування:

  • API конфігурація — URL, ключі, токени
  • Feed налаштування — формат (YML/XML), URL фіду, авторизація
  • Webhook — URL для прийому повідомлень, секретний ключ
  • Синхронізація — інтервали оновлення замовлень, залишків, цін
  • Продажі — авто-створення замовлень продажу, команда продажів
  • Клієнти — режим створення партнерів, пошук за телефоном/email

🔄 Cron завдання

Модуль створює 4 автоматичні завдання:

Завдання Інтервал Опис
Import Orders 15 хв Імпорт нових замовлень
Sync Stock 30 хв Оновлення залишків
Sync Prices 1 год Оновлення цін
Refresh Tokens 12 год Оновлення API токенів

📋 Статуси замовлень

Стандартні статуси замовлень:

  • Новий — щойно отримане замовлення
  • В обробці — замовлення обробляється
  • Підтверджений — замовлення підтверджено
  • Відправлений — замовлення відправлено
  • Доставлений — замовлення доставлено
  • Скасований — замовлення скасовано
  • Повернення — товар повернуто

🔌 Контролери

Модуль надає два HTTP контролери:

URL Призначення
/marketplace/feed/<id> Генерація YML/XML фіду для маркетплейсу
/marketplace/webhook/<id> Прийом webhook повідомлень

⚠️ Вимоги

  • Odoo 19 Community або Enterprise Edition
  • Модулі: sale, stock, delivery
  • Python бібліотека lxml (для генерації XML)

📦 Пов'язані модулі

  • l10n_ua_marketplace_rozetka — інтеграція з Rozetka
  • l10n_ua_marketplace_prom — інтеграція з Prom.ua
