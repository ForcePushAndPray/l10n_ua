# Ukraine - Education ЄДЕБО Integration

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Каркас інтеграції з Єдиною державною електронною базою освіти (ЄДЕБО) Міністерства освіти і науки України.

## Що увійшло

* **Wizard імпорту** (`l10n_ua.edebo.import`) — приймає CSV з колонками `last_name, first_name, birthdate, member_type` (і опційно `middle_name, student_number, rnokpp`). Збігає партнерів за РНОКПП або за іменем, оновлює існуючих, створює нових. Підтримує **dry-run** (тільки підрахунок без запису).
* **Wizard експорту** (`l10n_ua.edebo.export`) — вивантажує контингент у CSV з фільтром (всі / активні / випущені).
* **Точка розширення** `_parse_custom()` для реальних форматів обміну (XML за специфікацією МОН) — підключається окремими плагінами.

## Залежності

* `l10n_ua_education_base`

## Нормативна база

* **Постанова КМУ № 1098** — Положення про ЄДЕБО
* **Наказ МОН** про порядок надання даних до ЄДЕБО (актуальну редакцію звіряти на mon.gov.ua)

## Обмеження

⚠️ ЄДЕБО має закриту специфікацію XML-форматів обміну, яка регулярно оновлюється. Цей модуль реалізує **тільки CSV-інтерфейс** як базовий формат для роботи з електронними таблицями. Для реальної відправки в ЄДЕБО потрібний окремий плагін, що реалізує `_parse_custom()` для відповідного XML-формату.
