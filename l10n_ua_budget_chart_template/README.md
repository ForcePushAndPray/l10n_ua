# Ukraine - Budget Chart Template

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Окремий план рахунків бухгалтерського обліку в державному секторі —
Наказ Мінфіну № 1203 від 31.12.2013. Структурно відрізняється від
плану рахунків приватного сектору (НП(С)БО).

## Що увійшло

* **Chart template `ua_state`** через стандартний механізм Odoo 19
  `account.chart.template` з декораторами `@template()`.
* **~50 основних субрахунків** (4-значні коди), які покривають
  типовий цикл бюджетної установи:
  * Клас 1: основні засоби, нематеріальні активи, знос (10xx-14xx)
  * Клас 2: виробничі запаси, дебіторка, грошові кошти, реєстраційні рахунки (20xx-24xx)
  * Клас 5: внесений капітал, цільове фінансування, фінансові результати (51xx-55xx)
  * Клас 6: розрахунки з постачальниками/бюджетом/працівниками/підзвіт (62xx-66xx)
  * Клас 7: бюджетні асигнування, доходи від послуг, трансферти (70xx-75xx)
  * Клас 8: витрати на оплату праці, матеріальні, амортизація, трансферти (80xx-85xx)
  * Клас 0: позабалансові — орендовані ОЗ, бланки суворого обліку, бюджетні зобовʼязання
* **Базові журнали** — Реєстраційний рахунок (ДКСУ), Каса, Загальний журнал, Доходи від послуг, Закупівлі
* Кожен рахунок автоматично позначається `ua_budget_is_state_sector=True`
  для коректної інтеграції з `l10n_ua_budget_base`

## Регуляторна база

* **Наказ Мінфіну № 1203 від 31.12.2013** — https://zakon.rada.gov.ua/laws/show/z0161-14
  «Про затвердження Плану рахунків бухгалтерського обліку в державному секторі»
* **Наказ Мінфіну № 333 від 24.12.2012** — Типова кореспонденція субрахунків
* **Наказ Мінфіну № 1219 від 30.12.2022** — останні системні зміни

⚠️ Перед використанням у проді — звірити повний перелік субрахунків з
актуальною редакцією Наказу № 1203. Поточний пакет містить найуживаніші
~50 субрахунків, повний документ нараховує понад 150.

## Як використовувати

При створенні нової компанії в Odoo (`res.company`) і виборі України як
fiscal country — буде доступний шаблон `ua_state` поряд із приватним
планом рахунків. Завантаження через Settings → Companies.
