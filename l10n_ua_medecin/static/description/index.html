Україна — Заклади охорони здоров'я

ЦПМСД / АСМД / Лікарні / Поліклініки / ЕМД

Пацієнти, декларації з лікарем, НСЗУ-капітація, клінічна картка і інтеграція з eHealth — все для роботи в реформованій системі охорони здоров'я.

Що включено

l10n_ua_medecin_base

  • Тип закладу: ЦПМСД, АСМД, поліклініка, лікарня, ЕМД, діагностичний центр, санаторій, диспансер, лабораторія
  • Ліцензія МОЗ + ID НСЗУ як надавача послуг
  • ID закладу в Центральній компоненті eHealth
  • 13 медичних спеціалізацій (сімейна медицина, терапія, педіатрія, хірургія, кардіологія, неврологія, стоматологія тощо)
  • Окремі групи доступу: UA Medecin User / Manager

l10n_ua_medecin_patient

  • Пацієнти з прив'язкою до res.partner
  • Вікові категорії 0-5 / 6-17 / 18-39 / 40-64 / 65+ (для капітаційних коефіцієнтів НСЗУ)
  • Декларації з лікарем ПМД (Наказ МОЗ № 503)
  • Lifecycle декларації: draft → active → terminated
  • Автоматичне припинення попередньої при підписанні нової
  • eHealth UUID на декларації

l10n_ua_medecin_nszu

  • Договір з НСЗУ з повним lifecycle (draft → submitted → active)
  • 10 типів пакетів медичних послуг:
    ПМД-капітація, спеціалізована, стаціонар, ЕМД, пологи, онкологія, психіатрія, реабілітація, стоматологія
  • 5 моделей оплати: капітація / глобальний бюджет / за випадок / за послугу / змішана
  • Автоматичний розрахунок капітації:
    тариф × Σ(пацієнтів × ваговий коефіцієнт за віком)
  • Стартовий каталог 5 типових пакетів НСЗУ 2025

l10n_ua_medecin_clinical

  • Прийом пацієнта (encounter): консультація, профілактика, виклик додому, ЕМД, маніпуляція
  • Діагнози з прив'язкою до МКХ-10 (primary + concurrent)
  • Хронічні стани з датою встановлення і ступенем
  • Алергії з рівнем тяжкості
  • Каталог МКХ-10 (стартова вибірка)

l10n_ua_medecin_ehealth

  • HTTP-клієнт для Центральної компоненти eHealth (api.ehealth.gov.ua)
  • OAuth2 client_credentials flow
  • Реєстрація декларацій в eHealth при активації (hook в action_activate)
  • Лог усіх API-запитів з тілом запиту/відповіді
  • Dry-run режим за замовчуванням — без реальних запитів, тільки логування. Безпечно для перших налаштувань.
  • Налаштування через res.config.settings (API URL, credentials)

Як це виглядає

Картка пацієнта з історією декларацій

Договір з НСЗУ з розрахунком капітації

Капітаційний платіж НСЗУ розраховується автоматично: тариф × Σ(пацієнтів × ваговий коефіцієнт за віком) за Постановою КМУ № 240. Декларації при активації реєструються в eHealth (dry-run або реальний API).

Для кого

ЦПМСД / АСМД

Первинна медико-санітарна допомога. Декларації + капітація НСЗУ.

Поліклініки

Спеціалізована амбулаторна допомога за пакетами НСЗУ.

Лікарні

Стаціонарна допомога. Облік пацієнтів, випадків, виконання договору.

ЕМД

Станції екстреної медичної допомоги. Глобальний бюджет НСЗУ.

Як це працює

1. Декларація

Пацієнт обирає лікаря ПМД, декларація автоматично реєструється в eHealth (через dry-run або реальний API).

2. Капітація

НСЗУ-договір автоматично перераховує очікувану суму:
тариф × Σ(пацієнти × коеф. за віком)

3. Прийом

Лікар приймає пацієнта → encounter з діагнозом МКХ-10 і призначенням лікування.
