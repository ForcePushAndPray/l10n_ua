Налаштування типів відпусток

Основні параметри

  • Категорія UA (annual_basic, sick тощо)
  • Кількість днів на рік
  • Календарні чи робочі дні
  • Мінімальний безперервний період (14 днів)

Додаткові параметри

  • Чи переноситься на наступний рік
  • Максимум днів для перенесення
  • Потребує стажу (6 місяців)
  • Оплачувана / неоплачувана
  • Джерело оплати (роботодавець / ФСС)

Баланс відпусток

Облік залишків відпусток по кожному працівнику:

  • Належить днів — кількість днів на рік
  • Перенесено з минулого року — невикористані дні
  • Всього доступно — автоматичний розрахунок
  • Використано — затверджені відпустки
  • Заплановано — відпустки на розгляді
  • Залишок — доступно для використання

Компенсація при звільненні

  • Автоматичний розрахунок компенсації за невикористані дні
  • На основі середньоденної зарплати
  • Кнопка "Розрахувати компенсацію"

Графік відпусток

Річне планування відпусток працівників:

  • Планування по місяцях/кварталах
  • Прив'язка до типу відпустки
  • Статус виконання
  • Фактичні дати використання

Джерела оплати

  • Роботодавець — перші 5 днів
  • ФСС — з 6-го дня
  • Вагітність — 100% за рахунок ФСС

Автоматичні розрахунки

  • Кількість календарних днів
  • Відсоток оплати на основі стажу
  • Середньоденна зарплата (за 12 місяців)
  • Сума за рахунок роботодавця
  • Сума за рахунок ФСС
  • Загальна сума

Середня зарплата

Розрахунок середньої зарплати для відпусткових та лікарняних:

  • Розрахунковий період — 12 календарних місяців
  • Включаються — оклад, надбавки, премії (is_basic_salary)
  • Виключаються — періоди без роботи (лікарняні, відпустки без збереження)
  • Формула — сума доходів / календарні дні
  • Fallback — оклад з договору якщо немає розрахункових листків
