# Ukraine - Education Base

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Базовий модуль для українських освітніх установ — ЗДО, ЗЗСО, ПТУ, заклади
вищої освіти. Облік контингенту (учнів/студентів/вихованців), навчальних
груп та навчальних років з повним lifecycle.

## Можливості

* **Тип закладу освіти** на `res.company` — ЗДО / ЗЗСО / ліцей / ПТУ / ЗВО I-II / ЗВО III-IV / позашкільний.
  Додаткові поля: ліцензія, дата видачі, код ЄДЕБО, форма власності.
* **Навчальний рік** з контролем «один активний на установу», автоматичним
  обчисленням року закінчення, валідацією дат.
* **Навчальні групи** — універсальна модель для класів школи, груп ЗДО,
  курсових груп ВНЗ, груп ПТУ і позашкільних гуртків. Класний керівник /
  куратор (зв'язок з `hr.employee`), розрахункова чисельність, профіль.
* **Контингент** з повним lifecycle:
  `applicant → enrolled → studying → on_leave ↔ studying → graduated`
  (плюс `expelled` і `transferred` як термінальні).
  Mail.thread/activity для аудиту переходів. Прив'язка до `res.partner`
  обов'язкова, до `hr.employee` — опційно (для аспірантів-працівників).
* Унікальні номери особових справ у межах установи.
* Окремі групи доступу `UA Education User` / `UA Education Manager`.
* Окрема гілка меню «Освіта (UA)».

## Залежності

* `hr` (для зв'язку з працівниками-кураторами та аспірантами-співробітниками)
* `l10n_ua_account_base` (через цей депенденс ми спадково отримуємо
  українську локалізацію — RNOKPP/ЄДРПОУ, формати документів, регіони)

## Нормативна база

* Закон України «Про освіту» № 2145-VIII від 05.09.2017
* Закон України «Про вищу освіту» № 1556-VII від 01.07.2014
* Закон України «Про повну загальну середню освіту» № 463-IX від 16.01.2020
* Закон України «Про дошкільну освіту» № 2628-III від 11.07.2001
* Закон України «Про професійно-технічну освіту» № 103/98-ВР від 10.02.1998

## Що НЕ входить (буде в наступних модулях)

* Стипендії — `l10n_ua_education_scholarship` (з інтеграцією в `l10n_ua_hr_salary`).
* Інтеграція з ЄДЕБО (МОН) — `l10n_ua_education_edebo`.
* Облік дитячого харчування (для ЗДО та ШНЗ) — `l10n_ua_education_meals` (за потреби).
