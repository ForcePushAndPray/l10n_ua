# Ukraine - Budget Reports

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Друковані форми та офіційна звітність для українських бюджетних установ.
Поверх `l10n_ua_budget_estimate`.

## Що увійшло

* **Друкована форма кошторису** (Наказ Мінфіну № 44 від 28.01.2002) —
  кнопка «Друк → Кошторис (форма)» на формі кошторису. Окремі секції
  для загального і спеціального фондів, квартальні підсумки, місце для
  підписів керівника і головного бухгалтера.
* **Форма 2д** — Wizard «Бюджетний облік → Форма 2д (виконання заг. фонду)».
  Параметри: кошторис, період (I/II/III/IV квартал, півріччя, 9 місяців, рік).
  Звіт показує план vs касове виконання за обраний період з % виконання
  і залишком асигнувань.

## Що НЕ увійшло (для наступних PR)

* Форми 2м, 4-1д, 4-2д, 7д, 9д
* Меморіальні ордери 1-17
* Інтерактивні дашборди

## Регуляторна база

* **Наказ Мінфіну № 44 від 28.01.2002** — Порядок складання, розгляду,
  затвердження та основні вимоги до виконання кошторисів
* **Наказ Мінфіну № 44 від 24.01.2012** — Порядок складання фінансової,
  бюджетної та іншої звітності розпорядниками бюджетних коштів

⚠️ Перед використанням у проді — звірити макет з актуальною редакцією
наказів на rada.gov.ua. Шаблони відображають структуру форм, але не
претендують на пікселеву відповідність офіційному друкованому бланку.
