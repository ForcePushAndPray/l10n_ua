Україна - Декларація єдиного податку

Форма F0103309 для ФОП в Odoo 19

Про модуль

Модуль для створення Декларації платника єдиного податку (форма F0103309, версія 9) для фізичних осіб-підприємців.

Генерує XML-файл у форматі ДПС для подання через електронний кабінет платника податків.

Основні можливості

  • Майстер заповнення декларації
  • Генерація XML у форматі ДПС (кодування windows-1251)
  • Підтримка груп ФОП 1, 2, 3
  • Управління кодами КВЕД
  • Розрахунок доходу та податку
  • Експорт для подання в електронний кабінет

Скріншоти

Створення декларації єдиного податку

Вимоги

  • Встановлений модуль l10n_ua_tax_cabinet
