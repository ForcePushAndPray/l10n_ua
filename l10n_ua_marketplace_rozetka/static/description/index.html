🛒 Україна - Інтеграція з Rozetka

Повна інтеграція з маркетплейсом Rozetka для Odoo 19

📦 Про модуль

Модуль інтеграції з Rozetka Seller API для автоматизації продажів на найбільшому маркетплейсі України.

Розширює базовий модуль l10n_ua_marketplace_base функціоналом, специфічним для Rozetka.

✨ Основні можливості

  • Авторизація API — Bearer token з автоматичним оновленням (кожні 24 години)
  • Імпорт замовлень — автоматичне завантаження нових замовлень з пагінацією
  • Оновлення статусів — синхронізація статусів замовлень в обидві сторони
  • Синхронізація залишків — batch-оновлення залишків через API
  • Синхронізація цін — масове оновлення цін на товари
  • Webhook підтримка — миттєве отримання нових замовлень
  • YML фід — генерація товарного фіду для Rozetka

⚙️ Налаштування

  1. Встановіть модуль l10n_ua_marketplace_base
  2. Перейдіть до Маркетплейси → Конфігурація → Бекенди
  3. Створіть новий бекенд з типом Rozetka
  4. Введіть дані авторизації:
    • Seller ID — ваш ідентифікатор продавця
    • Username — логін від Rozetka Seller Portal
    • Password — пароль від порталу
  5. Натисніть Тест підключення для перевірки
  6. Активуйте бекенд

🔄 Автоматична синхронізація

Модуль підтримує автоматичну синхронізацію через Cron-завдання:
