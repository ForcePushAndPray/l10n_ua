Україна - Повна локалізація

Комплексне бізнес-рішення для Odoo 19

Встановлення всіх українських модулів одним кліком.
Повна заміна 1С:Підприємство, 1С:ЗУП та M.E.Doc.

Включені модулі

Кадри та зарплата

  • Управління персоналом (українська специфіка)
  • Військовий облік та бронювання
  • Трудові договори та графіки роботи
  • Розрахунок зарплати (ПДФО, ВЗ, ЄСВ)
  • ПСП (податкова соціальна пільга)
  • Відпустки, лікарняні (е-ТВН)
  • Табель обліку робочого часу (П-5)
  • Кадрові накази та друковані форми
  • Звітність до ПФУ та ДПС

Бухгалтерія та податки

  • Український план рахунків
  • Облік та звітність з ПДВ
  • Облік основних засобів
  • Інтеграція з Кабінетом платника
  • Підтримка ФОП
  • Податкова звітність (Ф0103309)
  • Шаблони документів

Банкінг

  • Синхронізація курсів валют НБУ
  • Інтеграція з ПриватБанком
  • Інтеграція з Monobank
  • Імпорт банківських виписок

Доставка

  • Інтеграція з Новою Поштою
  • Інтеграція з Укрпоштою
  • Інтеграція з Meest Express
  • Автоматичне створення ТТН
  • Відстеження доставки

Маркетплейси

  • Rozetka Seller API
  • Prom.ua API
  • Hotline.ua (прайс-фіди)
  • Price.ua (прайс-фіди)
  • Імпорт та синхронізація замовлень
  • Синхронізація залишків
  • Генерація YML-фідів

ПРРО (Каси)

  • Інтеграція з Checkbox
  • Фіскальні чеки
  • Z-звіти
  • Звітність до ДПС

Інше

  • Генерація платіжних посилань
  • Звіти та документи

Чому обрати цей пакет?

Один клік

Встановіть 30+ українських модулів одним кліком. Без ручного управління залежностями.

Повна відповідність

Трудове законодавство, податкові вимоги та звітність повністю реалізовані.

Заміна 1С

Повна заміна 1С:Підприємство та 1С:ЗУП із сучасним веб-інтерфейсом.
