## Базовий модуль

### l10n_ua_account_base — Фундамент локалізації

**Призначення:** Спільні довідники та утиліти для всіх модулів.

| Модель | Опис | Записів |
|--------|------|---------|
| `l10n_ua.kved` | Класифікатор КВЕД-2010 | ~1000 |
| `l10n_ua.koatuu` | Довідник КАТОТТГ | 19000+ |
| `l10n_ua.tax.office` | Податкові інспекції (ДПІ) | ~40 |
| `l10n_ua.legal.form` | Організаційно-правові форми | 19 |

**Розширення res.partner:**
- ЄДРПОУ (8 цифр з контрольною сумою)
- ІПН/РНОКПП (10 цифр з контрольною сумою)
- КВЕД (основний та додаткові)

**Утиліти (tools/):**
- `validators.py` — валідація ЄДРПОУ, ІПН, IBAN
- `formatters.py` — форматування дат, сум українською

## Бухгалтерія та податки

### l10n_ua_accounting — План рахунків П(С)БО

- План рахунків України (класи 0-9)
- Журнали-ордери, головна книга
- Оборотно-сальдова відомість

### l10n_ua_assets — Основні засоби

- Групи ОЗ за ПКУ (1-16)
- Методи амортизації
- Інвентарна картка ОЗ-6

### l10n_ua_tax — Податковий облік

- Податки: ПДФО 18%, ВЗ 5%, ЄСВ 22%, ПДВ 20%/7%/0%
- Податкові періоди
- Коди бюджетної класифікації

**Розширення res.company:**
- Організаційно-правова форма (ФОП, ТОВ, ПП, тощо)
- Податкова інспекція (ДПІ)
- Група єдиного податку (для ФОП)
- Ставка єдиного податку

### l10n_ua_account_vat — ПДВ

- Реєстр податкових накладних
- Податкова накладна (XML для ЄРПН)
- Розрахункова коригування
- Декларація з ПДВ

### l10n_ua_fop — Єдиний податок ФОП

- Книга обліку доходів
- Декларація платника ЄП
- Розрахунок ЄСВ для ФОП

### l10n_ua_tax_cabinet — Інтеграція з cabinet.tax.gov.ua

**Призначення:** Робота з електронним кабінетом платника податків.

**Основні моделі:**
- `l10n_ua.tax.cabinet.document` — Податковий документ
- `l10n_ua.tax.document.type` — Тип документа
- `l10n_ua.tax.document.wizard` — Майстер заповнення

**Типи документів:**
| Код | Назва |
|-----|-------|
| F0103309 | Декларація платника єдиного податку (ФОП) v9 |
| F0103405 | Декларація платника єдиного податку (ФОП) v5 |
| F0103308 | Звіт з ЄСВ |
| F0100210 | Декларація з ПДВ |
| J1201010 | Податкова накладна |

**Функціонал:**
- Завантаження/створення документів
- Заповнення даних через wizard
- Генерація XML (windows-1251)
- Перегляд XML/PDF

**Розширення res.company:**
- Коди діяльності (КВЕД) — One2many

### l10n_ua_tax_F0103309 — Декларація єдиного податку

**Призначення:** Заповнення декларації F0103309 для ФОП 1-3 груп.

**Поля декларації:**
- Група ФОП (1, 2, 3)
- Ставка єдиного податку
- Податкова інспекція
- Коди діяльності (КВЕД)
- Доходи по кварталах
- Податок по кварталах
- ЄСВ

## Встановлення

### Базові модулі:
```bash
# Фундамент
odoo-bin -d <database> -i l10n_ua_account_base --stop-after-init

# Бухгалтерія + податки
odoo-bin -d <database> -i l10n_ua_accounting,l10n_ua_tax --stop-after-init

# Податковий кабінет
odoo-bin -d <database> -i l10n_ua_tax_cabinet,l10n_ua_tax_F0103309 --stop-after-init
```

### HR модулі:
```bash
odoo-bin -d <database> -i l10n_ua_hr_base,l10n_ua_hr_contract,l10n_ua_hr_documents --stop-after-init
```

### Оновлення:
```bash
odoo-bin -d <database> -u l10n_ua_account_base,l10n_ua_tax_cabinet --stop-after-init
```

## Налаштування компанії

1. **Налаштування → Компанії → [Ваша компанія]**
2. Вкладка **"Ukrainian Tax Settings"**:
   - Організаційно-правова форма (ФОП, ТОВ, тощо)
   - Податкова інспекція
   - Група ФОП та ставка (якщо ФОП)
   - Коди діяльності (КВЕД)

## Типові сценарії

### Створення декларації ФОП:
1. Україна → Податковий кабінет → Документи → Створити
2. Вибрати тип: "Декларація платника єдиного податку (ФОП) v9"
3. Натиснути "Заповнити дані"
4. Заповнити доходи по кварталах
5. Натиснути "Згенерувати" → XML готовий

### Імпорт документа з cabinet.tax.gov.ua:
1. Україна → Податковий кабінет → Документи → Створити
2. Завантажити XML або PDF файл
3. Тип документа визначиться автоматично
