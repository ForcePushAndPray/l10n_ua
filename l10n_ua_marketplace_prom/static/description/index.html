🛍️ Україна - Інтеграція з Prom.ua

Повна інтеграція з маркетплейсом Prom.ua для Odoo 19

📦 Про модуль

Модуль інтеграції з Prom.ua API для автоматизації продажів на одному з найбільших маркетплейсів України.

Розширює базовий модуль l10n_ua_marketplace_base функціоналом, специфічним для Prom.ua.

✨ Основні можливості

  • Авторизація API — простий Bearer token без необхідності оновлення
  • Імпорт замовлень — автоматичне завантаження нових замовлень
  • Імпорт товарів — завантаження каталогу товарів з Prom.ua
  • Оновлення статусів — синхронізація статусів замовлень
  • Синхронізація залишків — оновлення наявності товарів
  • Синхронізація цін — оновлення цін на товари
  • Webhook підтримка — миттєве отримання нових замовлень
  • YML фід — генерація товарного фіду для Prom.ua

⚙️ Налаштування

  1. Встановіть модуль l10n_ua_marketplace_base
  2. Перейдіть до Маркетплейси → Конфігурація → Бекенди
  3. Створіть новий бекенд з типом Prom.ua
  4. Введіть дані авторизації:
    • API Key — токен з особистого кабінету Prom.ua
  5. Натисніть Тест підключення для перевірки
  6. Активуйте бекенд

🔑 Отримання API ключа

  1. Увійдіть до особистого кабінету Prom.ua
  2. Перейдіть до Налаштування → API
  3. Створіть новий API ключ
  4. Скопіюйте ключ та вставте в поле API Key в Odoo

Зверніть увагу: API ключ має права, які ви обрали при створенні. Для повної інтеграції потрібні права на замовлення, товари та синхронізацію.

🔄 Автоматична синхронізація

Модуль підтримує автоматичну синхронізацію через Cron-завдання:

Операція Інтервал за замовчуванням
Імпорт замовлень Кожні 15 хвилин
Синхронізація залишків Кожні 30 хвилин
Синхронізація цін Кожну годину

📥 Імпорт товарів

Модуль дозволяє імпортувати існуючий каталог товарів з Prom.ua:

  1. Відкрийте бекенд Prom.ua
  2. Натисніть кнопку Імпорт товарів
  3. Товари будуть додані до прайслиста бекенду
  4. Якщо товар знайдено в Odoo за артикулом — він буде зв'язаний

Ця функція корисна для першого налаштування або синхронізації каталогу.

⚠️ Вимоги

  • Встановлений модуль l10n_ua_marketplace_base
  • Активний аккаунт на Prom.ua
  • API ключ з особистого кабінету Prom.ua
  • Python бібліотека requests
