Україна — Заклади освіти

ЗДО / ЗЗСО / Ліцей / ПТУ / Заклади вищої освіти

Контингент учнів/студентів, навчальні роки, групи, стипендії, дитяче харчування, обмін з ЄДЕБО — все на одній платформі.

Що включено

l10n_ua_education_base

  • Тип закладу: ЗДО / ЗЗСО / ліцей / ПТУ / ЗВО I-II / ЗВО III-IV / позашкільний
  • Ліцензія МОН + код ЄДЕБО на res.company
  • Навчальний рік з контролем «один активний на установу»
  • Універсальна модель груп: клас школи, група ЗДО, курсова група, гурток
  • Контингент з повним lifecycle:
    applicant → enrolled → studying → on_leave ↔ studying → graduated
  • Прив'язка до hr.employee (для аспірантів-співробітників)
  • Mail.thread / activity для аудиту переходів
  • Унікальні номери особових справ у межах установи

l10n_ua_education_scholarship

  • Типи стипендій: академічна, соціальна, президентська, ВР, обласна
  • Відомості виплати з рядками по членах контингенту
  • Автоматичний розрахунок ПДФО (18%) і військового збору (5%)
  • Звичайні академічні стипендії звільнені від ПДФО (ПК ст. 165.1.26)
  • Генерація account.move з аналітикою КЕКВ/Фонд/КПКВК
  • State machine: draft → approved → paid
  • Автонумерація СТП-<рік>-<номер>

l10n_ua_education_meals

  • Технологічні картки страв з нормами закладки і виходу
  • Поживна цінність на порцію (ккал, БЖВ)
  • Меню на день за віковими групами
  • Облік присутності → автоматична кількість порцій
  • Для ЗДО за нормами ПКМУ № 1545 і Наказу МОЗ № 1073
  • Для шкіл за нормами ПКМУ № 305

l10n_ua_education_edebo

  • Wizard імпорту/експорту контингенту з ЄДЕБО (МОН)
  • CSV-формат за замовчуванням
  • XML-формат через окремий плагін l10n_ua_education_edebo_xml
  • Збіг партнерів за РНОКПП або ПІБ
  • Dry-run режим для перевірочних прогонів
  • Точка розширення _parse_custom() для специфічних форматів МОН

Як це виглядає

Клас з контингентом учнів

Відомість стипендій з автоматичним ПДФО і ВЗ

Преміальні стипендії автоматично розраховують ПДФО (18%) і військовий збір (5%) на кожному рядку. Натиснення «Виплатити» генерує проводку з аналітикою КЕКВ 2720 / Фонд / КПКВК.

Для всіх типів закладів

ЗДО

Дошкільні заклади. Облік вихованців, груп, харчування.

ЗЗСО

Школи 1-11(12) класи. Класні керівники, табелі, стипендії.

ПТУ

Профтехосвіта. Групи за спеціальностями, виробнича практика.

ЗВО

Університети, інститути, коледжі. Курси, спеціальності, стипендії.

Інтеграції

Бюджетний облік

Стипендії автоматично створюють проводки з КЕКВ 2720 і потрапляють до плану виконання кошторису через l10n_ua_budget.

Кадровий облік

Класні керівники, вчителі, тренери — через стандартний hr + надбудови l10n_ua_hr_* з військовим обліком і ПСП.
