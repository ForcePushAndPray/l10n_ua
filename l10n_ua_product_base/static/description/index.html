Коди УКТ ЗЕД і ДКПП

Два класифікаційні коди номенклатури — в одному місці, для всіх українських модулів

Що додає модуль

  • Код УКТ ЗЕД — код товару за Українською класифікацією товарів зовнішньоекономічної діяльності. Графа 3.1 податкової накладної, обов'язкова для товарів.
  • Код ДКПП — код послуги за ДК 016:2010. Графа 3.3 податкової накладної, обов'язкова для послуг.

Обидва поля — на картці номенклатури, на вкладці «Загальна інформація».

Чому окремим модулем

Код належить товару, а не документу, і той самий код потрібен податковій накладній, чеку ПРРО та фідам маркетплейсів. Тримати його тут дозволяє магазину на маркетплейсах мати ці поля, не встановлюючи бухгалтерську локалізацію з планом рахунків.

Перевірка формату

  • УКТ ЗЕД зберігається самими цифрами: крапки, пробіли й дефіси з митних документів прибираються при записі — у XML ЄРПН іде саме рядок цифр.
  • Довжина коду має відповідати рівню класифікатора: 4, 6, 8 або 10 цифр. Обірваний код відхиляється одразу, а не квитанцією ДПС.
  • ДКПП перевіряється за формою запису: двоцифрові групи через крапку, дефіс — лише перед останніми двома (62.01.11-00.00).

Технічний модуль: власного меню не має, працює через картку номенклатури.
