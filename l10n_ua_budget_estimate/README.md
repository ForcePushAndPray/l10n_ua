# Ukraine - Budget Estimate (Кошториси)

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Кошториси та контроль виконання плану асигнувань для українських бюджетних
установ. Поверх `l10n_ua_budget_base`.

## Можливості

* **Документ «Кошторис»** з державною машиною:
  `draft` → `submitted` → `approved` → `executed` → `closed`
  (плюс `cancelled`). Окремі гілки для затвердження/скасування/повернення в чернетку.
* **Рядки кошторису** з аналітикою КЕКВ × фонд × період. Розпис по 12 місяцях
  з автоматичним обчисленням квартальних і річних підсумків.
* **Касове виконання** обчислюється з `account.move.line` за тим же роком,
  КЕКВ, фондом, КПКВК. Доступний % виконання, залишок і кольорове підсвічування
  рядків, що перевиконано (≥100%) або наближаються до ліміту (≥90%).
* **Розрахунок окремо по фондах** — загальний / спеціальний.
* **Довідки про зміни** (амендменти) через посилання `parent_estimate_id`.
* Інтеграція з `mail.thread` (чатер, активності).
* Окремий зведений вид всіх рядків — для аналізу через множину кошторисів
  (наприклад, скільки витрачено на КЕКВ 2110 у всіх установах за рік).

## Залежності

* `l10n_ua_budget_base` (КЕКВ/КФК/КПКВК/КВКВ + поля на account.move.line)

## Нормативна база

* **Бюджетний кодекс України ст. 75-78** — порядок складання, розгляду та
  затвердження бюджетних запитів і кошторисів
* **Наказ Мінфіну № 44 від 28.01.2002** — «Про порядок складання,
  розгляду, затвердження та основні вимоги до виконання кошторисів» —
  актуальну редакцію звіряти на rada.gov.ua
* **Наказ Мінфіну № 333 від 12.03.2012** — інструкція щодо КЕКВ (через
  залежність на `l10n_ua_budget_base`)

## Як користуватися

1. Створіть новий кошторис: **Бухгалтерія → Налаштування → Бюджетний облік (UA) → Кошториси**.
2. Заповніть шапку — рік, фонд, КПКВК (опційно).
3. У вкладці «Рядки кошторису» додайте КЕКВ-рядки з помісячним розписом.
4. Подайте на затвердження → Затвердьте → Запустіть виконання.
5. Касове виконання заповнюється автоматично з проведених проводок.
   Кнопка «Перерахувати касове виконання» примусово перераховує.

## Обмеження

* Касове виконання поки що рахується лише по `debit` рядків. Для повноцінного
  обліку (включно з кредитуванням) потрібне розширення в `l10n_ua_budget_treasury`.
* Друкована форма кошторису і план використання — буде в `l10n_ua_budget_reports`.
* Поки що немає інтеграції з ДКСУ — реальні платіжки і виписки розглядатимуть
  у `l10n_ua_budget_treasury`.
