Україна - Інтеграція з NovaPay

Банківські виписки через API бізнес-кабінету NovaPay для Odoo 19

Про модуль

Модуль отримує виписки рахунків NovaPay через API бізнес-кабінету (business.novapay.ua) і формує з них банківські виписки Odoo.

Розширює базовий модуль l10n_ua_bank_sync функціоналом, специфічним для NovaPay.

Основні можливості

  • Авторизація JWT за логіном, refresh-токеном і відкритим сертифікатом із кабінету
  • Автоматичне оновлення одноразового refresh-токена: новий токен зберігається одразу й не губиться, навіть якщо синхронізація завершилася помилкою
  • Автоматичний пошук рахунку NovaPay за IBAN банківського журналу
  • Імпорт виписки за період: напрям операції, контрагент, його IBAN та ЄДРПОУ, призначення платежу
  • Залишки на початок і кінець періоду з оборотів рахунку — контроль повноти виписки
  • Захист від дублювання операцій при повторній синхронізації того самого періоду
  • Автоматична синхронізація за розкладом і повторна обробка збереженої відповіді

Як підключити

  1. У кабінеті business.novapay.ua відкрийте Система → Налаштування → API і натисніть «Згенерувати».
  2. Створіть підключення банку з провайдером NovaPay і банківським журналом, у якому вказано IBAN рахунку NovaPay.
  3. Заповніть логін кабінету, вставте refresh-токен і відкритий сертифікат.
  4. Натисніть «Перевірити з'єднання», далі «Отримати рахунки» — модуль знайде рахунок за IBAN, і можна синхронізувати виписки.

Вимоги та обмеження

  • Встановлений модуль l10n_ua_bank_sync
  • Рахунок NovaPay для бізнесу та доступ до бізнес-кабінету
  • Refresh-токен одноразовий: не використовуйте ту саму пару токен/сертифікат в іншій системі — після генерації нової пари в кабінеті вставте її в підключення
