Ukraine - HR Salary Bonus

Модуль управління преміями для української локалізації зарплатного обліку. Дозволяє вести облік премій працівників з інтеграцією в розрахунок заробітної плати.

Основні можливості

  • Облік премій працівників з різними типами
  • Налаштування податкових параметрів для кожного типу премії (ПДФО, військовий збір, ЄСВ)
  • Автоматичне включення підтверджених премій у розрахунковий листок
  • Відстеження статусу премій: чернетка → підтверджено → виплачено
  • Можливість заповнення премій із зовнішніх систем
  • Підтримка української мови

Як використовувати

  1. Увімкніть бонусну систему для працівника у вкладці "Бонусна система" картки працівника
  2. Створіть премію через меню Зарплата → Премії → Премії
  3. Підтвердіть премію натиснувши кнопку "Підтвердити"
  4. Розрахуйте зарплату — премія автоматично додасться до нарахувань
  5. Після проведення розрахункового листка премія автоматично отримає статус "Виплачено"
Важливо: Премії включаються в розрахунок зарплати тільки якщо:
  • У працівника увімкнена бонусна система
  • Премія має статус "Підтверджено"
  • Дата премії потрапляє в період розрахункового листка

Інтеграція із зовнішніми системами

Модуль підтримує заповнення премій через API Odoo, що дозволяє інтегрувати зовнішні системи обліку продуктивності, CRM або інші джерела даних про премії.
