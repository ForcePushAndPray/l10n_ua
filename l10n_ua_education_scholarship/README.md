# Ukraine - Education Scholarship

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

Стипендії для учнів і студентів. Поверх `l10n_ua_education_base` +
`l10n_ua_budget_base`.

## Що увійшло

* **Типи стипендій** (`l10n_ua.scholarship.type`): академічна (звичайна/підвищена), соціальна, президентська, ВР, обласна, іменна. Датовані місячні ставки за рівнем освіти, резервна базова сума, КЕКВ за замовчуванням, прапорець оподаткування ПДФО.
* **Відомість виплати** (`l10n_ua.scholarship.payment`) з рядками по членах контингенту. State machine: `draft → approved → paid` (+ `cancelled`).
* Бюджетна аналітика на відомості: КЕКВ (за замовчуванням з типу), фонд, КПКВК. Якщо встановлено `l10n_ua_budget_treasury` — спрацьовує контроль ліміту при проведенні платежу.
* Автонумерація `СТП-<рік>-<номер>` через `ir.sequence`.
* Унікальність: один член контингенту → один рядок у відомості.
* Меню «Освіта (UA) → Стипендії: відомості», налаштування типів через «Освіта (UA) → Налаштування → Типи стипендій».
* 17 тестів.

## Регуляторна база

* **Постанова КМУ № 1047 від 28.12.2016** — розміри стипендій
* **Постанова КМУ № 1050 від 28.12.2016** — питання стипендіального забезпечення
* **Постанова КМУ № 314 від 12.03.2026** — зміни, чинні з 01.09.2026

Ставка для відомості визначається за її місяцем і типом закладу освіти компанії. Якщо датованої ставки немає, використовується `monthly_amount` типу стипендії.
