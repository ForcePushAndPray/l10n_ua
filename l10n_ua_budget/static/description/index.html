Україна — Бюджетна установа

Повний стек обліку для розпорядників бюджетних коштів

Класифікатори, кошториси, ДКСУ-інтеграція і офіційні форми звітності в одному пакеті. Заміна 1С:БГУ для бюджетних установ.

Що включено

l10n_ua_budget_base

  • КЕКВ — економічна класифікація (~55 кодів з ієрархією)
  • КФК — функціональна класифікація (~75 кодів, COFOG)
  • КПКВК — програмна класифікація
  • КВКВ — відомча класифікація (ГРБК)
  • Розширення account.account/move.line з аналітикою фонду
  • Валідація узгодженості фонду рядка з обмеженням рахунку

l10n_ua_budget_chart_template

  • План рахунків Наказу Мінфіну № 1203
  • ~115 субрахунків класів 1-8 + позабалансові
  • Готові журнали для держсектору

l10n_ua_budget_estimate

  • Документ «Кошторис» з повним lifecycle (draft → approved → executed)
  • Помісячний розпис → автоматичні квартальні і річний підсумки
  • Касове виконання — агрегація з проводок (план vs факт)
  • Окремий розрахунок по загальному та спеціальному фондах
  • Mail.thread / activity для аудиту
  • Довідки про зміни через parent_estimate_id

l10n_ua_budget_treasury

  • Довідник органів ДКСУ (27 установ)
  • Тип казначейського рахунку на account.journal
  • Автоматичний контроль ліміту асигнувань на проведенні платежу
  • Імпорт виписки ДКСУ (CSV / DBF через plugin)

l10n_ua_budget_reports

  • Друкована форма Кошторису (Наказ Мінфіну № 44 від 28.01.2002)
  • Форма 2д — Звіт про виконання загального фонду
  • Форма 2м — Виконання загального фонду місцевих бюджетів
  • Форма 4-1д / 4-2д — Звіти спецфонду
  • Форма 7д — Заборгованість за бюджетними коштами
  • Форма 9д — Дебіторська заборгованість
  • Меморіальні ордери 1-17 (накопичувальні відомості)

Як виглядає кошторис

Кошторис із помісячним розписом по КЕКВ, автоматичним розрахунком квартальних і річних підсумків, касовим виконанням (агрегація з проводок з аналітикою КЕКВ/Фонд).

Для кого

Освіта

ЗДО, ЗЗСО, ПТУ, ЗВО. Кошториси, фонди, КПКВК для МОН (220).

Медицина

ЦПМСД, лікарні. Кошториси + НСЗУ-капітація як одне ціле.

ОМС та держоргани

Міські/селищні ради, виконкоми, держустанови всіх рівнів.

Нормативна база

  • Бюджетний кодекс України № 2456-VI
  • Наказ Мінфіну № 11 від 14.01.2011 — Бюджетна класифікація
  • Наказ Мінфіну № 333 від 12.03.2012 — Інструкція з КЕКВ
  • Наказ Мінфіну № 1203 від 31.12.2013 — План рахунків держсектору
  • Наказ Мінфіну № 44 від 28.01.2002 — Порядок складання кошторисів
  • Наказ Мінфіну № 44 від 24.01.2012 — Бюджетна звітність
  • Наказ Мінфіну № 938 від 28.10.2015 — Казначейське обслуговування

Чому це краще за 1С

Веб-доступ

Робота з будь-якого пристрою, без VPN до сервера 1С.

Open source

LGPL-3 — без vendor lock-in, можна адаптувати під свої потреби.

Контроль ліміту

Автоматична перевірка асигнувань — неможливо проводити понад план (ПКМУ 1608).
