## l10n_ua_agreement — Договори

Облік договорів з клієнтами: від генерації з шаблону до підписання та
виставлення рахунків. Призначено для ФОП і підприємств, що надають послуги
за договором.

### Можливості

- **Об'єкт «Договір»** зі станом: Чернетка → На підписанні → Підписаний
- **Генерація з шаблону** для конкретного замовника (друкована форма QWeb)
- **Електронний підпис** через `sign_oca`: кнопка «Надіслати на підпис» →
  після повного підписання договір автоматично переходить у стан «Підписаний»,
  підписаний PDF зберігається у договорі
- **Додаткові угоди** як дочірні договори (`parent_agreement_id`)
- **Типи договорів** (Послуги, Поставка товарів, Підряд, Абонентське
  обслуговування) з аналітикою
- **Акт наданих послуг** — друкована форма з договору
- **Продажі та разові рахунки** з договору (через `agreement_sale`)
- **Періодичні (абонентські) рахунки** через `contract.contract`

### Архітектура

```
agreement + agreement_sale + sign_oca + contract   (OCA, 19.0)
        └── l10n_ua_agreement
              ├── Договір: стан, дод. угоди, акт, друкована форма
              ├── Міст до sign_oca (override _check_signed)
              ├── Міст до contract (поле agreement_id)
              └── Українізація UI базового agreement
```

### Структура меню

```
Договори
├── Договори          — список договорів
├── Звітність
│   └── Аналіз договорів — pivot/graph (сума за типом і станом)
└── Налаштування
    └── Типи договорів
```

### Потік роботи

1. Створити договір (заповнити клієнта, предмет, суму, строк) або згенерувати з шаблону
2. «Сформувати документ» → PDF
3. «Надіслати на підпис» → запит `sign.oca.request`, клієнт підписує у порталі
4. Після підпису договір автоматично «Підписаний», підписаний PDF у договорі
5. З договору — продажі/разові рахунки або періодичний `contract.contract`
6. За фактом надання — друк «Акта наданих послуг»

### Інтеграція з ФОП

Рахунки з договорів стають джерелом доходу для `l10n_ua_fop` (книга обліку
доходів, 5% ЄП від надходжень).

### Встановлення

```bash
# OCA-залежності (гілка 19.0) мають бути в addons_path
odoo-bin -d <db> -i l10n_ua_agreement --stop-after-init
```
