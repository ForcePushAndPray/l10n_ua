## 1. Що треба знати про облік НПО

- **Неприбуткова організація** — це юрособа, внесена контролюючим органом до
  **Реєстру неприбуткових установ та організацій** з присвоєнням **ознаки
  неприбутковості** (п. 133.4 ПКУ; Порядок ведення Реєстру — постанова КМУ від
  13.07.2016 № 440). Доходи такої організації не оподатковуються податком на
  прибуток, якщо вони використовуються **виключно** на утримання організації,
  реалізацію мети й напрямів діяльності, визначених установчими документами,
  і **не розподіляються** між засновниками, членами, працівниками (крім оплати
  праці та ЄСВ), членами органів управління й пов'язаними з ними особами.
- Ознака неприбутковості — чотиризначний код:

  | Код | Група |
  |-----|-------|
  | 0031 | бюджетні установи |
  | 0032 | громадські об'єднання |
  | 0033 | політичні партії |
  | 0034 | творчі спілки |
  | 0035 | релігійні організації |
  | 0036 | благодійні організації |
  | 0037 | пенсійні фонди |
  | 0038 | спілки |
  | 0039 | асоціації та інші об'єднання юридичних осіб |
  | 0040 | житлово-будівельні кооперативи |
  | 0041 | дачні (дачно-будівельні) кооперативи |
  | 0042 | садівничі та гаражні кооперативи (товариства) |
  | 0043 | ОСББ, асоціації власників жилих будинків |
  | 0044 | професійні спілки, їх об'єднання та організації профспілок |
  | 0045 | організації роботодавців та їх об'єднання |
  | 0046 | сільськогосподарські обслуговуючі кооперативи |
  | 0047 | кооперативні об'єднання с/г обслуговуючих кооперативів |
  | 0048 | інші юрособи, діяльність яких відповідає п. 133.4 ПКУ |

- **Цільові надходження** (благодійна допомога, гранти, цільові внески)
  спершу обліковуються на рахунку **48 «Цільове фінансування і цільові
  надходження»** — це ще не дохід. За **П(С)БО 15 «Дохід», п. 17** отримане
  цільове фінансування **визнається доходом протягом тих періодів, у яких були
  зазнані витрати**, пов'язані з виконанням умов цільового фінансування.
  Тобто дохід місяця = витрати програми за місяць; у результаті цільова
  діяльність дає нульовий фінансовий результат, а на 48 лишається невикористаний
  залишок.
- Цільове фінансування капітальних інвестицій (купівля ОЗ за рахунок гранту)
  визнається доходом пропорційно амортизації цих об'єктів (П(С)БО 15, п. 18).
  У модулі це виходить автоматично, якщо проводки амортизації таких ОЗ мають
  аналітику програми.
- Замість декларації з податку на прибуток НПО подає **Звіт про використання
  доходів (прибутків) неприбуткової організації** — щорічно протягом 60 днів
  після закінчення року, разом із фінансовою звітністю (п. 46.2 ПКУ). Місячний
  звіт подається лише в разі порушення вимог п. 133.4 ПКУ.

## 2. Встановлення модуля

**Застосунки → пошук `l10n_ua_nonprofit` → Встановити.** Модуль залежить від
`l10n_ua_accounting` (закриття періоду, бухгалтерські звіти UA) і встановить
його, якщо потрібно.

Після встановлення з'являються:

| Де | Пункт меню |
|----|------------|
| Бухоблік → Бухгалтерія → **Неприбуткова організація** | Цільові програми, Визнання цільового доходу |
| Бухоблік → Звітність → Бухгалтерські звіти | **Звіт за цільовими програмами**, **Звіт про використання доходів (НПО)** |
| Налаштування → Компанії → вкладка **«Неприбуткова організація»** | налаштування компанії |
| Бухоблік → Закриття → Закриття періоду → вкладка **«Цільовий дохід (48)»** | визнання доходу під час закриття |

Пункти меню бачать користувачі з групою «Бухгалтер UA»; права — стандартні групи
обліку Odoo (Бухгалтер — повний доступ, «лише читання» — перегляд).

## 3. Налаштування компанії

**Налаштування → Користувачі та компанії → Компанії → ваша організація →
вкладка «Неприбуткова організація».**

1. Позначте **«Неприбуткова організація»**.
2. **Код ознаки неприбутковості** — з рішення контролюючого органу (для ГО —
   `0032`, для благодійного фонду — `0036`).
3. **Дата** і **номер рішення** про включення до Реєстру — друкуються в полі 7
   звіту.
4. Натисніть **«Налаштувати рахунки та журнал»**. Модуль:
   - знайде в плані рахунків субрахунок **48x** (у стандартному плані Odoo:
     481–484, за замовчуванням береться 483 «Благодійна допомога») або створить
     рахунок `483`;
   - знайде або створить **718 «Дохід від безоплатно одержаних оборотних
     активів»** — рахунок, у кредит якого визнається цільовий дохід;
   - створить журнал **«Цільове фінансування»** (код `NPO`).
5. **Рахунки витрат програм** — префікси рахунків, витрати на яких з
   аналітикою програми вважаються витратами програми. За замовчуванням `8,9`.
   Якщо організація веде і клас 8, і клас 9 (списує 8 → 23/9х), лишіть один
   клас, інакше витрати порахуються двічі. Малі НПО зазвичай ведуть лише клас 9
   (92 «Адміністративні витрати», 94 «Інші витрати операційної діяльності») —
   тоді вкажіть `9`.
6. **«Визнавати цільовий дохід під час закриття періоду»** — лишіть увімкненим.

Також заповніть стандартні реквізити компанії: **ЄДРПОУ**, адресу, телефон,
**податкову інспекцію** (поле з `l10n_ua_tax`), а в картці контрагента компанії —
ПІБ керівника й головного бухгалтера: вони підставляються у звіт.

## 4. Цільові програми й джерела фінансування

**Бухоблік → Бухгалтерія → Неприбуткова організація → Цільові програми →
Створити.**

Програма — це одиниця цільового фінансування: грант донора, благодійний збір,
членські внески, гуманітарна допомога. Для кожної програми модуль створює
**аналітичний рахунок** у плані «Цільові програми» — саме ним програма
позначається в проводках.

| Поле | Що вказати |
|------|-----------|
| Назва, Код | «Грант «Чиста вода» 2026», `WATER-26` |
| Тип фінансування | Благодійна допомога / Добровільні пожертви / Гуманітарна допомога / Грант, технічна допомога, бюджетне фінансування / Членські внески / Активи на статутні цілі / Інше |
| Донор | контрагент-донор (для зборів від багатьох жертводавців — порожньо) |
| Початок, Кінець, Бюджет | з грантової угоди / кошторису |
| Рахунок цільового фінансування | 48x (за замовчуванням — з компанії) |
| Рахунок визнаного доходу | 718 (або 719) |
| Рядок доходу у звіті | підставляється з типу фінансування, можна змінити |
| Рядок видатків у звіті | `2.3` — утримання й статутна діяльність; `2.4.1`/`2.4.2` — якщо програма **передає** допомогу благонабувачам |

Відповідність типу фінансування рядку доходу Звіту:

| Тип | Рядок |
|-----|-------|
| Благодійна допомога | 1.6.1 |
| Добровільні пожертви, безповоротна фін. допомога | 1.6 |
| Гуманітарна допомога | 1.6.2 ГД |
| Грант / технічна допомога / бюджет | 1.4 |
| Членські внески | 1.7 |
| Активи на статутні цілі | 1.5 |
| Інше | 1.11 |

Натисніть **«Активувати»**. Програми в стані «Чернетка» не беруть участі у
визнанні доходу. Завершену програму **закрийте** — вона й далі потрапляє у звіти.

На формі програми видно підсумки на сьогодні: **Отримано**, **Витрачено**,
**Визнано доходом**, **Залишок на 48**, **Витрати, ще не покриті доходом**,
**Залишок бюджету**; кнопка **«Проводки»** відкриває всі рядки журналу з
аналітикою програми.

## 5. Надходження: пожертви, гранти, членські внески

Надходження на рахунок проводяться як завжди — з банківської виписки
(звірка) або ручною проводкою. Головне — **кредит рахунку 48x з аналітикою
програми**:

```
Дт 311 «Поточні рахунки в нац. валюті»   10 000,00
    Кт 483 «Благодійна допомога»          10 000,00   аналітика: Грант «Чиста вода»
```

У звірці банківської виписки оберіть рахунок 483 для контррядка й заповніть
колонку **Аналітика** програмою. Членські внески — так само, з програмою
«Членські внески» (тип «Членські внески» → рядок 1.7 звіту).

Негрошові надходження (товари, продукти, ліки): `Дт 20/28 – Кт 48` з
аналітикою програми.

## 6. Витрати за програмами

Будь-які витрати, які фінансуються програмою, мають **аналітику програми** на
рядку рахунку витрат (клас 9 або 8):

- рахунок постачальника — колонка **Аналітика** в рядку рахунку;
- авансовий звіт, ручна проводка, амортизація — так само;
- одна витрата на кілька програм — розподіл у відсотках (50 % / 50 %).

```
Дт 92 «Адміністративні витрати»    4 000,00   аналітика: Грант «Чиста вода»
    Кт 631 «Розрахунки з постачальниками»     4 000,00
```

Передача допомоги благонабувачам — витрати (наприклад, 949) з аналітикою
програми, у якої рядок видатків `2.4.1` (благодійна) або `2.4.2 ГД`
(гуманітарна).

Витрати без аналітики програми — витрати на утримання організації; у звіті
вони потрапляють у рядок 2.3.

## 7. Визнання доходу з рахунку 48

Модуль рахує дохід програми **з проводок**, тому однаково враховує згенеровані,
ручні та сторновані записи:

> **Дохід до визнання = витрати програми до дати − дохід, визнаний раніше,**
> але **не більше залишку на 48** програми.

- Якщо витрат більше, ніж грошей на 48, різниця лишається «не покритою» і
  визнається пізніше, коли надійдуть нові кошти.
- Якщо витрату сторновано (повернення від постачальника) після визнання,
  наступне визнання буде від'ємним — проводка `Дт 718 – Кт 48`.

**Вручну:** Бухоблік → Бухгалтерія → Неприбуткова організація → **Визнання
цільового доходу → Створити**, вкажіть дату (кінець місяця), за потреби —
програми, натисніть **«Обчислити»**, перевірте рядки (витрати до дати, визнано
раніше, залишок на 48, дохід до визнання) і **«Провести»**:

```
Дт 483 «Благодійна допомога»   4 000,00   аналітика: Грант «Чиста вода»
    Кт 718 «Дохід від безоплатно одержаних оборотних активів»   4 000,00
```

Кнопка **«Скасувати»** сторнує проводку тією ж датою; після «В чернетку» можна
перерахувати.

## 8. Закриття місяця

**Бухоблік → Закриття → Закриття періоду**, як зазвичай (див.
[accounting.md](accounting.md), флоу 4). Для неприбуткової компанії закриття
**перед** закриттям рахунків доходів і витрат саме визнає цільовий дохід
місяця (так само, як списує витрати/доходи майбутніх періодів 39/69):

1. визнання `Дт 48 – Кт 718` за всіма активними програмами на останній день
   місяця;
2. закриття 7х/9х на 79х — дохід 718 і витрати програм взаємно гасяться;
3. 79х → 441/442.

Повторне закриття того самого місяця нічого не дублює. **Сторно закриття**
сторнує й визнання; після повторного закриття воно формується знову. Вкладка
**«Цільовий дохід (48)»** на формі закриття показує проведене визнання.

## 9. Звіт за програмами

**Бухоблік → Звітність → Бухгалтерські звіти → Звіт за цільовими програмами.**
Вкажіть період, за потреби — донора або програми, **«Обчислити»** або
**«Друк»**.

| Колонка | Зміст |
|---------|-------|
| Бюджет | бюджет програми |
| Залишок на початок (48) | залишок цільових коштів на початок періоду |
| Отримано | кредит 48 за період |
| Визнано доходом | списано з 48 у дохід за період |
| Повернено / інше | інші дебети 48 (повернення донору тощо) |
| Залишок на кінець (48) | початок + отримано − визнано − повернено |
| Витрачено за період | витрати з аналітикою програми |
| Витрати, ще не покриті доходом | на кінець періоду |
| Використано бюджету, % | витрати від початку / бюджет |

Звіт зручно додавати до звіту донору.

## 10. Звіт про використання доходів неприбуткової організації

**Бухоблік → Звітність → Бухгалтерські звіти → Звіт про використання доходів
(НПО) → Створити.**

1. **Рік** (за замовчуванням — попередній), **Період** «Рік» (місячний — лише у
   разі порушення п. 133.4 ПКУ: період з початку року до кінця місяця
   порушення), **Тип звіту**: Звітний / Звітний новий / Уточнюючий.
2. **«Обчислити»** — модуль заповнює Частину І з оборотів рахунків за рік
   **без проводок закриття періоду**:
   - **доходи** (клас 7, крім 79) — за правилами бухобліку, тобто визнаний
     дохід, а не гроші на 48; з аналітикою програми — у рядок програми; без
     програми: 72х/73х → 1.9 «пасивні доходи», 718/745 → 1.6, решта → 1.11;
   - **видатки** (рахунки витрат програм) — з аналітикою програми у рядок
     видатків програми (2.3/2.4.х/2.6), без програми → 2.3;
   - рядки 1, 1.6, 2, 2.4 — суми підрядків; вкладка **«Розшифровка»** показує
     суму за рядком, програмою й рахунком.
3. **Частина ІІ** (нецільове використання — рядки 3.1 ГД, 3.2; розподіл
   доходів — рядок 4) заповнюється вручну, лише якщо вимоги п. 133.4 ПКУ
   порушено; рядок 5 = 3 + 4, рядок 6 = 5 × 18 % (ставка п. 136.1 ПКУ).
   Рядки 7–10 — виправлення помилок (рядок 10 = 7 × 3 % в уточнюючому).
4. **«Додатки»** — позначки ГД (операції з гуманітарною допомогою; ставиться
   автоматично, якщо є суми в 1.6.2/2.4.2), ВП, ФЗ і склад фінансової звітності
   (повна / малого підприємництва / спрощена).
5. **«Друк»** — PDF за формою, затвердженою наказом Мінфіну від 17.06.2016
   № 553 (у редакції наказу від 28.04.2017 № 469). Фінансову звітність
   (Баланс, Звіт про фінансові результати) друкуйте з бухгалтерських звітів
   `l10n_ua_accounting`.

> **Електронне подання.** Електронна форма ДПС цього звіту — **J0101911**
> (додатки ГД — J0119711, ВП — J0119811, за Реєстром форм звітності ДПС).
> XSD-схему з сайту ДПС отримати автоматично не вдалося, тож **XML-вивантаження
> модуль поки не формує**: перенесіть суми з друкованої форми в Електронний
> кабінет або M.E.Doc/FREDO.

## 12. Обмеження й ручні дії

- **XML-подання** звіту (J0101911) не формується — немає перевіреної XSD.
- **Додатки ГД і ВП** не друкуються — лише позначки наявності в звіті.
- **Частина ІІ** (нецільове використання) не визначається автоматично: модуль
  не може знати, яка витрата суперечить установчим документам.
- **Капітальні інвестиції** за рахунок гранту (п. 18 П(С)БО 15): дохід
  визнається пропорційно амортизації лише якщо амортизація має аналітику
  програми; придбання ОЗ (рахунок 10х) витратою не вважається.
- Розподіл неприбуткових рядків для бюджетних установ (1.1–1.3, 2.1–2.2)
  автоматично не заповнюється — для них є модулі `l10n_ua_budget*`.
- Фінансова звітність НПО (Ф1/Ф2, Ф1-м/Ф2-м) — з `l10n_ua_accounting`.
