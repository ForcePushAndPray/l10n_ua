## 0. Застосунок

Меню застосунків → **Податки**. Верхнє меню: **Податкові документи**, **Податкові періоди**,
**ПДВ**, **Податковий кабінет**, **FOP (Simplified Tax)**, **Налаштування**.

Базові ставки (модуль `l10n_ua_tax`, у налаштуваннях компанії «Ukrainian Tax Settings»):

| Податок | Ставка |
|---------|--------|
| ПДФО | 18 % |
| Військовий збір | 5 % |
| ЄСВ | 22 % |
| ПДВ | 20 % / 7 % / 0 % |
| Єдиний податок (ФОП) | 2–5 % (групи 1–4) |

> _Скриншот:_ `00-menu.png`

## 1. ПДВ

**Податки → ПДВ.** Підменю:

- **Податкові накладні:** _Видані_, _Отримані_, _All Tax Invoices_ — податкова накладна
  формує XML для ЄРПН; ставка 20 % за замовчуванням, кнопка створення накладної з рахунку;
- **Реєстри ПДВ:** _Issued Register_, _Received Register_ — реєстри виданих/отриманих ПН;
- **Декларації з ПДВ** — декларація з рядками та кнопкою перегляду балансу рахунку **6411**
  (пошук рахунку фільтрується по компанії);
- **Ліміт реєстрації**, **Registration Deadlines** — контроль ліміту реєстрації ПН і термінів.

> Звірено наживо на демо (декларації з ПДВ, 5 записів). Приклад — **02/2026**:
> податкове зобов'язання 12 043,60 ₴, податковий кредит 31 920,60 ₴ →
> **до відшкодування 19 877,00 ₴** (кредит − зобов'язання); стани проходять
> _Розраховано → Подано → Прийнято_.

> _Скриншоти:_ `01-vat-menu.png`, `02-vat-declaration.png`

## 2. Єдиний податок ФОП (F0103309)

**Податки → FOP (Simplified Tax).**

1. **Книга обліку доходів** — рядки доходу; автозаповнення з банківської виписки;
2. **Декларація платника ЄП** — оберіть рік, період (квартал/півріччя/9 міс./рік) і групу
   ФОП. Дохід підтягується з книги, податок рахується автоматично:
   - **Група 3:** єдиний податок = дохід × 5 %;
   - військовий збір ФОП = дохід × 1 %;
   - ЄСВ = мінзарплата × місяців × 22 %;
3. **Кнопка «Згенерувати XML»** формує валідний XML **форми F0103309** для подання до ДПС
   (через спільний генератор `l10n_ua_tax_F0103309`) і зберігає файл у декларації.

> Раніше кнопка була заглушкою — тепер формує реальний XML (issue #139).

> _Скриншот:_ `03-fop-declaration.png`

## 3. Об'єднана звітність 4ДФ

Модуль `l10n_ua_tax_4df` — квартальний Податковий розрахунок ПДФО/ВЗ/ЄСВ (заміна 1ДФ + Д5):

- автозаповнення з нарахувань зарплати (`l10n_ua_hr_salary`);
- поквартальне формування, XML-експорт.

Доступ — через застосунок **Співробітники → Звітність** або меню звітності зарплати.

> _Скриншот:_ `04-4df.png`

## 4. Податковий кабінет ДПС

**Податки → Податковий кабінет** (`l10n_ua_tax_cabinet`) — єдина точка роботи з документами
для електронного кабінету:

| Документ | Код |
|----------|-----|
| Декларація ЄП (ФОП) | F0103309 (в. 9), F0103405 (в. 5) |
| Звіт з ЄСВ | F0103308 |
| Декларація з ПДВ | F0100210 |
| Податкова накладна | J1201010 |

Заповнення через wizard, генерація XML (windows-1251), перегляд XML/PDF.

> _Скриншот:_ `05-tax-cabinet.png`

---

## 5. Податкові періоди

**Податки → Податкові періоди** — довідник звітних періодів (місяць/квартал/рік), до яких
прив'язуються декларації та закриття.
