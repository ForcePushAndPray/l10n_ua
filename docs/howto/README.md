# HOWTO — покрокові сценарії по доменах

← [Назад до головної](../../README.md)

Практичні гайди «як зробити» для кожного домену української локалізації Odoo 19.
Приклади звірялися на демо-сервері **[demo.ndev.online](https://demo.ndev.online)**
(компанія _ТОВ «Тестова Компанія»_, користувач `demo`). Демо-базу **можна наповнювати**
під час тестування — дані не видаляються.

### Легенда перевірки

| Позначка | Значення |
|----------|----------|
| ✅ **звірено наживо** | Флоу пройдено на демо, розрахунки/значення підтверджені |
| 🟢 **внутрішні флоу** | Проходиться на демо без зовнішніх систем |
| 🔑 **потребує ключів** | Виконання наживо потребує зовнішніх креденшалів (банк/маркетплейс/ПРРО) |
| 📦 **OCA-залежності** | Потрібні OCA-модулі в `addons_path` |
| 🚧 **каркас/бета** | Частина функціоналу — заглушки; у гайді позначено чесно |

## Скріншоти

Кожен гайд містить іменовані плейсхолдери скріншотів (`> _Скриншот:_ name.png`) і теку
`img/<домен>/` для файлів. Скріншоти додаються окремо (браузерне середовище автоматичного
збереження у репозиторій наразі недоступне).

## Наскрізь звірені значення (приклади з демо)

- **HR — розрахунковий лист РЛ-2026-00048:** нарахування 50 000 ₴ → ПДФО 18 % = 9 000 ₴,
  ВЗ 5 % = 2 500 ₴, ЄСВ 22 % = 11 000 ₴ (роботодавець) → до виплати **38 500 ₴**.
- **Бухгалтерія — ОЗ-0005 «Планшет»:** метод «зменшення залишку», місячна амортизація
  582,12 ₴; 4 проведені рядки → знос 2 536,27 ₴; проведення формує Дт витрати / Кт 131.
