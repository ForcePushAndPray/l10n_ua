Табель обліку робочого часу

Щомісячний облік робочого часу працівників:

Основні функції

  • Автоматична генерація рядків для працівників
  • Заповнення днів з урахуванням календаря
  • Інтеграція з відпустками та лікарняними
  • Облік надурочних та нічних годин

Підсумки

  • Заплановано днів/годин
  • Відпрацьовано днів/годин
  • Дні відпустки та лікарняного
  • Неявки та прогули

Виробничий календар

Налаштування робочих та святкових днів:

  • Робочі дні — стандартний графік
  • Вихідні — субота, неділя
  • Святкові дні — офіційні свята України
  • Перенесені дні — робочі суботи
  • Скорочені дні — напередодні свят

Звіт П-5

Друк табелю за типовою формою П-5:

  • Офіційна форма "Табель обліку робочого часу"
  • Автоматичне заповнення по працівниках
  • Коди та години по кожному дню
  • Підсумки відпрацьованих днів/годин
  • Місце для підпису відповідальної особи

Інтеграція з payroll

Зв'язок табелю з розрахунком зарплати:

  • scheduled_hours — планові години для розрахунку
  • worked_hours — фактично відпрацьовані години
  • overtime_hours — надурочні для нарахування доплат
  • night_hours — нічні для нарахування доплат
  • payslip_id — прив'язка до розрахункового листка

Інтеграція

  • hr.leave — автоматичне відображення відпусток
  • hr.sick.leave — автоматичне відображення лікарняних
  • hr.payslip — дані для нарахування зарплати
  • hr.contract — визначення активних працівників

Залежності

Потребує:
  • l10n_ua_hr_base — базовий модуль української HR локалізації
  • l10n_ua_hr_holidays — модуль відпусток та лікарняних
