Україна - Податковий кабінет

Інтеграція з cabinet.tax.gov.ua через КЕП

Опис модуля

Модуль забезпечує інтеграцію Odoo з електронним кабінетом платника податків (cabinet.tax.gov.ua). Дозволяє синхронізувати податкові документи (декларації, звіти, квитанції) з використанням КЕП (кваліфікованого електронного підпису) від ІІТ.

Основні можливості

  • Синхронізація документів — автоматичне завантаження з податкового кабінету
  • Підтримка КЕП — автентифікація через кваліфікований електронний підпис
  • Зберігання документів — декларації, звіти, квитанції в Odoo
  • Перегляд XML — вбудований переглядач XML документів
  • Категоризація — документи за типом та періодом
  • Ручне завантаження — імпорт XML та PDF файлів
  • Типи документів — довідник типів податкових документів
  • Безпека — пароль КЕП не зберігається

Вимоги: Бібліотека IIT EUSignCP

Для роботи з КЕП необхідно встановити бібліотеку IIT EUSignCP від Інституту Інформаційних Технологій:

  • Завантаження: iit.com.ua/downloads
  • Встановлення: sudo mkdir -p /opt/iit/eu/sw && cp -r EUSignCP-Linux/sw/x64/* /opt/iit/eu/sw/
  • Залежності: sudo apt-get install libssl-dev libcurl4-openssl-dev
  • Сертифікати АЦСК: acskidd.gov.ua

Підтримувані формати ключів КЕП

  • .dat — файловий ключ ІІТ
  • .jks — Java KeyStore
  • .pfx / .p12 — PKCS#12
  • .zs2 — захищене сховище ключів ІІТ

Docker

Для використання в Docker додайте до Dockerfile:

RUN apt-get update && apt-get install -y libssl-dev libcurl4-openssl-dev wget unzip
RUN mkdir -p /opt/iit/eu/sw /opt/iit/certificates \
    && cd /tmp \
    && wget -q https://iit.com.ua/download/productfiles/EUSignCP-Linux-20241205.zip \
    && unzip -q EUSignCP-Linux-20241205.zip \
    && cp -r EUSignCP-Linux/sw/x64/* /opt/iit/eu/sw/ \
    && chmod -R 755 /opt/iit/eu/sw
RUN cd /opt/iit/certificates && wget -q https://acskidd.gov.ua/download/CACertificates.p7b
ENV IIT_LIB_PATH=/opt/iit/eu/sw
ENV IIT_CERT_PATH=/opt/iit/certificates
